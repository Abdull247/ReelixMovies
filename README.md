✨ Features

· 🎬 Browse your movie library — a clean, modern interface built with Material 3
· 🔍 Search & discover — find what you want to watch fast
· 🌐 Web + Android — same experience across both platforms, synced through Firebase
· 🔐 Account support — sign in to keep your library and preferences in sync
· 🎨 Dark-friendly UI — comfortable viewing any time of day
· ⚡ Fast & native — built with Kotlin and Jetpack Compose for smooth performance

📲 Installation (Android)

1. Tap the Download link above (or scan the QR code if provided).
2. Your browser will download the APK file.
3. Open the file. If prompted, allow installation from your browser or file manager:
   · Settings → Apps → Special access → Install unknown apps → [Your browser] → Allow
4. Tap Install and you're done.
